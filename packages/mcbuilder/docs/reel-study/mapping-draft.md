## Conventions

- **Reel aliases** (the readers' own): `alixxa` = alixxa-tower; `trixy` = trixyblox-ruined-temple; `gothic` = gothic-castle; `heavy` = heavy-tower; `niitty` = niitty-wizard-tower; `tall` = tall-mansion; `jp` = japanese-house; `pillar` = pillar-wall-design (4 still images, cited by file stem, e.g. `pillar/115564_3_ck17`); `FM` = french-mansion; `AR` = arashy12-medieval-house; `GS` = gorillo-spruce-house; `GV` = gorillo-survival-house; `NS` = noes-starter-house; `DB` = disruptive-builds (builds B1-B15 are inside this one reel); `hib` = hibouk-winter-mansion; `tav` = omggamer-medieval-tavern; `dio` = dio-rods-waterfall-quarry (7 photos cited `dio/q01`-`q07`, no f_ numbers).
- **Readers:** A = towers (`evidence/A-towers.md`), B = houses, C = disruptive-builds, D = hibouk / tavern / dio rods.
- **Frames:** cited as `reel/f_NNN`, at most 4 per row. A hyphen range means consecutive frames the reader cited as a range.
- **Confidence:** H / M / L as the reader stated it. `n/s` = the reader gave none. `sheet-level` = contact sheet only, so low. `(INF)` = the reader marked the claim INFERRED. No confidence is upgraded in this file.
- **Labels:** SHAPE / NEW SHAPE / PARAM / COMPOSITION / BLOCKED, as in the reader brief. Where this file's label differs from a reader's, the difference is listed under "Conflicts between readers".
- **Block IDs:** copied from the readers, with their `?` kept. None were added.
