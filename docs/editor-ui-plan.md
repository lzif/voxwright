## 2. Design spec & component mapping (restyle-in-place)

### 2.1 Scope boundary: Game UI vs `.ore-editor`

- **Stays Game Ore UI (`--band: 4px`, Pixelify Sans buttons/headers, `surface-page`/`surface-panel`):**
